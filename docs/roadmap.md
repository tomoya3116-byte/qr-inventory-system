# Roadmap

このロードマップは、Ver2.0 Web Phase 11 までの到達点と、次に進めるべき作業を整理するための作業メモです。
詳細仕様は `docs/v2_spec.md`、公開・運用方針は `docs/deployment_plan.md` と `docs/production_setup.md` を参照してください。

## 現在地

現在は Ver2.0 Web Phase 11 相当まで進んでいます。
CUI版・GUI版を残したまま、FastAPIベースのWeb版で日常操作、管理者操作、CSV、QR、バックアップ、操作ログ、QRスキャン運用まで扱える状態です。

## Phase 11: QRスキャン運用

状態: 完了

- [x] QRコードの標準URLを `/scan/{item_id}` 形式に整理する。
- [x] スマートフォンでQRコードを読み取って品目確認画面を開けるようにする。
- [x] スキャン後の画面から入庫、出庫、品目詳細へ進める導線を用意する。
- [x] CUI / GUI 生成時は `QR_INVENTORY_SCAN_BASE_URL` で絶対URLを埋め込めるようにする。
- [x] Web画面からのQR生成時は、アクセス中のWebアプリURLをもとに絶対URLを埋め込む。
