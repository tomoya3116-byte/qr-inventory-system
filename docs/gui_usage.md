# GUI版の使い方

CustomTkinterを使ったGUI版は、現場作業者が日常操作を直感的に行えるようにした画面です。
左側のメニューから機能を選び、右側の画面で作業します。

```bash
python src/gui_main.py
```

GUI版 Phase 1 で利用できる機能は以下です。

- 品目検索: 品目IDまたはQRコードで品目情報を確認
- 品目一覧: 全品目の一覧表示と更新
- 入庫: 品目ID・数量・作業者・備考を入力して在庫を追加
- 出庫: 在庫不足を確認しながら在庫を減算
- 最低在庫アラート: `current_stock <= min_stock` の品目を一覧表示

GUI版 Phase 2 では、CUI版で提供していた品目マスタ管理と棚卸修正をGUIから操作できます。

- 品目登録: 品目ID / 品名 / 型式 / メーカー / 保管場所 / 単位 / 最低在庫数 / 初期在庫数 / 備考を入力して登録
  - 登録時の `qr_code` は品目IDと同じ値で保存されます。
  - 品目ID・品名・最低在庫数・初期在庫数が未入力、または在庫数が不正な場合は日本語のエラーを表示します。
- 品目編集: 品目IDで検索し、既存のマスタ情報をフォームに表示してから更新
  - 更新後は画面内の「品目一覧を開く」から一覧を表示し、反映結果を確認できます。
- 棚卸修正: 品目IDで現在庫を表示し、実在庫数入力時に差異を確認してからADJUST履歴を記録
  - 実行前に確認ダイアログを表示します。
  - 実行直前に `backups/auto_stock_adjust_YYYYMMDD_HHMMSS.db` の自動バックアップを作成します（DB作成済みの場合）。

## GUI版の動作確認例

1. `pip install -r requirements.txt` を実行
2. `python src/gui_main.py` を実行
3. 品目検索で `ITEM-0001` を検索
4. 品目一覧を表示
5. `ITEM-0001` を数量 `1` で入庫
6. `ITEM-0001` を数量 `1` で出庫
7. 最低在庫アラートを表示
8. 品目登録で `ITEM-9001` などのテスト品目を登録
9. 品目編集で `ITEM-9001` を検索し、保管場所や最低在庫数を更新
10. 棚卸修正で `ITEM-9001` の実在庫数を入力し、確認ダイアログで実行

## GUI通常メニューと管理者メニュー

GUI版は、現場作業者向けの通常メニューと、危険操作・管理操作をまとめた管理者メニューを分離しています。

### GUI通常メニュー

通常メニューでは、日常作業に必要な以下の機能だけを表示します。

- **品目検索**: 品目IDまたはQRコードで品目情報・保管場所・在庫を確認します。
- **品目一覧**: 登録済み品目を一覧表示し、最新状態へ更新できます。
- **入庫**: 品目ID・数量・作業者・備考を入力して入庫履歴を記録します。
- **出庫**: 在庫不足を防ぎながら出庫履歴を記録します。
- **最低在庫アラート**: 現在庫が最低在庫以下の品目を確認します。

### GUI管理者メニュー

左メニューの「管理者メニュー」を押すと、パスワード入力ダイアログが表示されます。認証に成功した場合のみ、画面上に「管理者モード」と表示され、以下の管理機能を利用できます。

- **品目登録**
- **品目編集**
- **品目削除**: 削除前確認と品目ID再入力を行い、入出庫履歴がある品目は削除できません。
- **棚卸修正**: 実行前に確認ダイアログを表示し、自動バックアップを作成します。
- **CSV品目マスタ取込**: 文字コード、登録予定件数、更新予定件数、エラー件数、エラー詳細をプレビューします。エラーがない場合のみ取込実行できます。
- **CSV取込プレビュー**: CSV取込画面内の「プレビュー」ボタンで実行します。
- **QRコード生成（単品）**: 指定した品目IDのPNGを `qr_codes/` に保存します。
- **QRコード生成（全件）**: 全品目分のPNGを `qr_codes/` に保存します。
- **QRコード印刷用HTML生成**: `labels/qr_labels_YYYYMMDD_HHMMSS.html` を生成します。
- **DBバックアップ**: `backups/inventory_YYYYMMDD_HHMMSS.db` を作成します。
- **DB復旧**: `backups/` 内のバックアップを選択し、`RESTORE` 確認後に復旧します。復旧前には現在DBを自動バックアップします。

管理者モードを終了する場合は「管理者モード終了」を押してください。通常メニューに戻ります。

## 管理者パスワード

- 初期管理者パスワードは `admin123` です。
- 環境変数 `QR_INVENTORY_ADMIN_PASSWORD` を設定すると、管理者パスワードを変更できます。

```bash
export QR_INVENTORY_ADMIN_PASSWORD='任意の強いパスワード'
python src/gui_main.py
```

`admin123` は初期開発用のパスワードであり、本番運用では変更必須です。現在のパスワード方式は簡易ロックであり、本格的な認証ではありません。本格運用では、環境変数、設定ファイルのハッシュ化、OSアカウント権限などを検討してください。

## GUI管理者機能の動作確認例

1. `pip install -r requirements.txt`
2. `python src/gui_main.py`
3. 通常メニューで品目検索・入庫・出庫ができることを確認
4. 「管理者メニュー」を開く
5. 誤ったパスワードで拒否され、「パスワードが違います」と表示されることを確認
6. `admin123` で管理者モードに入れることを確認
7. CSV品目マスタ取込画面でCSV取込プレビューができることを確認
8. QRコード生成画面で単品生成または全件生成ができることを確認
9. DBバックアップ画面でバックアップを作成できることを確認
10. DB復旧画面で復旧実行時に `RESTORE` 確認が必要なことを確認
11. 「管理者モード終了」で通常メニューに戻れることを確認

生成物の `qr_codes/*.png`、`labels/*.html`、`backups/*.db` はGit管理しません。
